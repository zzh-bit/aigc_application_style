## 零、应用描述与创新点（AI 视频生成输入）

### 应用描述

**PS²（Parallel Self 2.0）** 是一个 AI 驱动的多自我决策伙伴。核心洞察：重大决策时人内心有多个声音在打架（冲/稳/长远看），PS² 用 AI 分别扮演这些声音展开结构化辩论，并生成可视化决策路径。**不替你决策，帮你"看清自己"。**

### 核心创新点（8 个）

1. **多 Agent 人格辩论** — 激进/保守/未来三派系 + 主持人，各有一套价值观+思维模型+语气的 system prompt，并行调用 LLM 生成多视角观点，模拟内心辩论
2. **Grounded-First 推演引擎** ★ — 路径结构（几条路、叫什么名）由规则确定，语义（描述/评分/情绪）由 LLM 丰富。解决纯 LLM 推演路径不稳定、不可复现的致命问题
3. **个人记忆 RAG** — IndexedDB 本地存储 + LLM 摘要 + 多维检索（关键词/分句/二元组/Jaccard），议会辩论时自动注入相关记忆，让 AI 引用你的真实经历
4. **未来信件系统** ★ — 三重智能触发（日期/情绪/事件），时空双向对话线程，送达时三派系角色批注，预测 vs 现实偏差可视化，时间长河拖拽探索
5. **全生命周期闭环** — 辩论→推演→归档→记忆检索→洞察→信件验证，形成认知飞轮
6. **导师智库** — 8 位思想家（苏格拉底/荣格/卡尼曼/老子等）以各自思维模型对话，可导入议会成为永久参与者
7. **情绪感知干预** — 30+ 类情绪信号词库 + 否定检测，检测焦虑自动触发呼吸引导（4s吸-2s屏-4s呼）
8. **Server+APK 双模** — 同一代码库同时产出 Web 部署版和 Android APK 离线版

### 视频应突出的 3 个最强创新

- **创新 2**（推演引擎）：三条确定路径 + LLM 丰富语义 = 可对比的人生路径图
- **创新 4**（未来信件）：三重触发 + 时空对话 + 议会批注 + 时间长河
- **创新 1**（人格辩论）：不是问 AI 得一个答案，而是让内心声音有序辩论

## 三、叙事推演演示（0:55 - 1:30）

| 画面 | 旁白 |
|------|------|
| 录屏：点击"生成推演"按钮 → 推演视图展开 | **叙事推演。** |
| 路径图展示 2-4 条分支（如"留在北京" vs"去西安发展"） | 基于你的议题，PS² 自动生成 2 到 4 条不同的路径。每一条路径都有详细的推演描述——不是泛泛而谈的模板，而是**基于你真实情况的具体分析**。 |
| 点击展开某一条路径的详情：收益评分、风险评分、情绪预测 | 每条路径都附带了收益评分、风险评估和情绪预测，你可以对比每条路径的利弊。 |
| 切换到底部"派系意见"面板 | 更关键的是，三个 AI 角色会对每条路径发表独立意见——激进派可能给"去西安"打高分，保守派则力挺"留在北京"。**你看到的不是一面之词，而是多维度的权衡。** |

> 字幕高亮：路径名、评分数字，标注"收益""风险""情绪预测"

## 五、未来信件 ★ 核心亮点（2:00 - 2:50）⭐ 最长展示

| 画面 | 旁白 |
|------|------|
| 切换到未来信件页面，特写"写一封信给未来的自己"界面 | （音乐转情感向）这可能是 PS² 最特别的功能——**未来信件。** |
| 演示写信：输入"半年后的我，你有没有后悔这个选择？"，选择触发方式 → 演示三种触发类型切换（日期/情绪/事件） | 你可以给未来的自己写一封信，设置时间胶囊在半年后送达。但不止于此——**三重智能触发**：你可以设日期触发，也可以让 AI 在检测到你某天情绪低落时自动送达，还可以绑定人生事件，比如"第一次收到心仪公司的面试通知时"。 |
| 演示收信界面：一封信到达，展示"议会批注"区域（三个角色各自写了批注） | 当信送达时，你不会只收到一封信。三位 AI 角色会附上他们的**智慧批注**——激进派可能说"你看，当初勇敢是对的"，保守派则说"这次谨慎让你避了个坑"。 |
| 演示回信功能：点击回信，开始写回信 | 收到信后你可以回信，然后对方再回信——形成一条**穿越时间的对话线程**，过去的你、现在的你、未来的你，在时空中连线。 |
| 切换到时间长河视图：一条可拖拽的横向时间线，不同年份节点闪烁，点击展开信件 | 而**时间长河**，把抽象的时间关系变成了一条可探索的河流。拖拽滑动，每一个节点都是一个年份，藏着那年你写给自己的信。**视觉化你的人生决策轨迹。** |

> 字幕高亮："三重触发""议会批注""时空线程""时间长河" 关键词单独弹出标注
