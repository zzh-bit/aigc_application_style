# Parallel Self 2.0（PS²）软件功能说明

> 本文档为产品功能概述，供交付、评审或对内说明使用。  
> 文档中不包含任何个人身份信息。

---

## 1. 产品定位

Parallel Self 2.0（以下简称 **PS²**）面向**复杂个人决策**场景，将多视角议会对话、**虚拟导师一对一对话**、情绪状态管理、决策路径可视化、个人记忆沉淀与未来信件、以及决策后的数据统计与复盘整合为一条**可持续迭代的决策闭环**，帮助用户在理性梳理与情绪调节两条线上同步推进选择质量。

---

## 2. 核心功能模块

### 2.1 多派系议会对话

- 用户围绕现实议题发起讨论后，系统以**激进派、保守派、未来派**等差异化立场生成互补观点，并由**主持人**收束为可讨论的结论与行动方向。
- 支持**可选导师角色**参与同一议题，提供跨视角的补充与纠偏（与下文的「导师单独对话」为两种入口，可组合使用）。
- 在服务端不可用时，提供**本地兜底回复**，降低弱网或接口异常对主流程的中断影响。

### 2.2 导师智库与虚拟导师单独对话

- **导师库**：提供多类**虚拟导师角色**（不同思想流派与对话风格，如理性分析、哲学思辨、战略视角等），供用户按需求挑选，而非仅依赖议会中的固定多派系组合。
- **一对一单独对话**：用户从导师库进入后，可与所选导师进行**独立会话**，与议会场的多角色轮替讨论相互分离；适合对单一议题做连续追问、深挖前提与行动边界，而不打断议会节奏。
- **与议会的关系**：议会中仍可通过「邀请导师」将某位导师**拉入同一场多角色讨论**；导师库单独对话则侧重**单导师、长对话、深对话**，两者互为补充。

### 2.3 情绪监测与调节

- 基于用户输入内容进行**情绪相关信号分析**，驱动界面中的情绪状态展示（如压力/平静等维度的可视化）。
- 当检测到**高焦虑等阈值**时，可触发**呼吸引导 / 冥想式调节**流程，帮助用户在高压下先稳定状态再继续决策。
- 情绪相关状态支持在会话周期内**持久化**，跨页面返回时保持连贯体验。

### 2.4 决策推演（决策树 / 路径可视化）

- 根据议会上下文归纳议题，生成**多条可选路径**，展示概率、收益、风险、情绪预测等结构化信息。
- 支持在路径节点上查看**各派系对该路径的态度与支持度**，便于对比取舍。
- 支持**分支对比**（两条路径并排对比收益、风险、情绪差异及文字摘要）。
- 路径详情以**底部抽屉**等形式呈现，避免小屏设备上内容被裁切或遮挡；在线推演失败时可回退到**本地规则骨架**，保证可用性。

### 2.5 记忆库（本地优先）

- 用户可维护多条**记忆条目**（如生活、工作、学习、情绪等维度），含摘要与关键词等字段。
- 在议会对话中，系统可对相关记忆做**检索与引用提示**，使建议更贴合用户自身语境与历史约束。
- 数据以**本地持久化**为主策略，适配移动端与离线场景下的可读可写。

### 2.6 未来信件

- 支持用户撰写面向未来或回应过去的**信件**，并可配置**触发条件**（如时间、情绪、关键词事件等）。
- 在满足条件时触发**送达提示**，与主流程形成“承诺—回顾—再决策”的辅助闭环。

### 2.7 数据洞察

- 在用户完成**决策归档**后，对历史记录进行聚合统计，例如：归档数量、复盘频率、情绪分布、主题分布等。
- 主题维度可按固定类别（如生活、工作、旅行、学习、情绪）进行归类展示。
- 支持结合归档数据生成**模式说明与偏见类提示**（如冲动倾向、拖延规避、风险偏好等），用于下一轮自我校准。

### 2.8 系统与体验层能力

- **统一深色主题界面**：议会、**导师单独对话**、记忆库、推演、洞察、设置等模块在同一视觉体系下组织。
- **可配置项**（具体以产品设置为准）：如回复长度与语气、派系强度、情绪触发阈值、是否上传归档至服务端、信件通知开关等。
- **Web 应用 + Android 壳（WebView）**交付形态：静态资源可打包进应用，便于离线分发与安装体验。

---

## 3. 数据与隐私原则（概述）

- **API 密钥与模型调用**应仅配置在服务端环境，避免写入前端或安装包明文。
- **本地优先**：会话、记忆、信件、部分洞察基线等可在终端侧持久化，减少对单一在线链路的依赖。
- **用户可控**：通过设置项管理上传策略、通知与体验参数（以实际实现为准）。

---

## 4. 典型使用流程（端到端）

1. 在议会页输入现实议题，查看多派系与主持人（及可选导师）的建议；或从**导师库**进入，与某一虚拟导师进行**单独对话**以深挖议题。  
2. 打开推演页，比较不同路径的收益、风险与情绪预测，并查看派系意见。  
3. 结合记忆库中的条目与导师补充，收敛为可执行方案。  
4. 点击「决策完成」将本轮对话**归档**。  
5. 在数据洞察中查看趋势与模式提示，为下一轮议题做准备。  
6. 按需使用未来信件与呼吸引导，强化长期承诺与当下状态管理。

---

## 5. 适用场景（示例）

- 职业路径、城市去留、学业与深造规划等重大选择前的结构化讨论。  
- 高压 deadline 或情绪波动明显时，先调节状态再推进决策。  
- 希望把零散判断沉淀为可复盘数据，减少重复性认知偏差的用户。
