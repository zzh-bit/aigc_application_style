## 四、详细任务清单

### 🔥 P0-1：修复推演路径 description 质量

**对应评分**：创新性·产品功能（+3 分）
**文件**：`lib/projection-grounded.ts`
**预计耗时**：2-3 天

**问题根因**：
1. `buildBranchForOption()` 中 `rawDesc` 是泛化模板（约 1471-1473 行）
2. `sanitizeBranchDescription()` 无效时 fallback 到模板（约 1448-1451 行）
3. 本地兜底不传 LLM，几乎总是模板

**改法**：
1. 在 `buildBranchForOption()` 中接入领域识别（`detectDomainKind()`），匹配 career/move/relationship 等领域文案
2. `sanitizeBranchDescription()` 拒绝匹配 `/走这一结果路径|收益、风险与节奏随该方向倾斜/` 的模板
3. 本地兜底 `buildGroundedProjectionFromCouncil()` 也传入议会 context 用于 enrich
4. 运行 `npm run verify:projection:topics` 验证

**验收标准**：
- 18 条测试议题矩阵中，description 不再出现模板套话
- 每条路径 description ≥ 50 字且有具体推演内容
- 验证脚本全部通过

### 🔥 P0-2：制作作品介绍 PPT

**对应评分**：完成度·资料齐全度 + 应用价值·前景评估
**预计耗时**：3-5 天

**PPT 结构（按官方模板）**：

```
Part 1：团队介绍（1-2 页）
  - 团队成员、学校、角色分工
  - 指导老师

Part 2：作品简介（2-3 页）
  - 作品名称：Parallel Self 2.0（PS²）
  - 一句话定位：AI 驱动的多自我决策伙伴
  - 核心效果呈现：3-4 张实际产品截图
    - 议会辩论界面
    - 叙事推演路径图
    - 记忆库 + 导师智库
    - 数据洞察报告

Part 3：作品策划（4-6 页）★ 重点
  - 设计理念：
    - 问题洞察：重大决策靠直觉 → 需要结构化 AI 辅助
    - 核心洞察：人内心有多个声音 → 用 AI 模拟多自我辩论
    - 设计哲学：不是替你决策，是帮你"看清自己"
  - 产品原型设计与效果展示：
    - 信息架构图
    - 核心交互流程（议题→辩论→推演→归档→洞察）
    - 全部使用实际产品截图，不用设计稿
  - 创新点说明（3 个核心创新）：
    1. 多 Agent 人格辩论架构（vs. 单轮 AI 问答）
    2. Grounded-First 叙事推演（结构确定 + LLM 语义丰富）
    3. 全生命周期决策闭环（辩论→推演→记忆→洞察→信件）
  - 前景评估：
    - 目标用户：大学生（择业）、职场人（转型）、面临重大选择的人
    - 市场规模：每年 900 万毕业生 + 数亿职场人
    - 竞品对比表（vs. 心理咨询 App / 社交发帖 / 通用 AI 问答）
    - 商业模式简述（可选）

Part 4：附录/技术说明（1-2 页）
  - 技术架构图
  - 大模型应用说明：6 个 API 端点 + DeepSeek
  - 双构建模式：Server + Export(APK)
```

**PPT 制作要点**：
- 使用统一深色主题（与产品 UI 一致）
- 每页不超过 5 个要点
- 截图使用 `1920×1080` 分辨率
- 避免大段文字，用图表和截图说话
- 创新点部分用对比表格突出差异化
